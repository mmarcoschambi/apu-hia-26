│ Fallback:   Si no hay EMAs, sale cuando Close < SMA 20            │
│ Resultado:  Captura movimientos extendidos, salida limpia         │

🛠️ CAMBIOS EN CÓDIGO:

1. ESTRUCTURA Position (daily_engine.py, líneas 28-44)
   ────────────────────────────────────────────────────
   + tp2_hit: bool = False           # Flag Fase 2
   + initial_shares: int = 0         # Posición original
   + R_inicial: float = 0.0          # Entry - Stop
   + adr_valor: float = 0.0          # ADR del símbolo

2. INICIALIZACIÓN DE POSICIÓN (líneas 225-254)
   ────────────────────────────────────────────
   + Calcular R_inicial en entrada
   + Calcular ADR (promedio high-low últimos 20 días)
   + Guardar initial_shares
   + TP1 trigger cambiado de +1.5R a +1.0R

3. SISTEMA DE 3 FASES (líneas 323-378)
   ────────────────────────────────────
   FASE 1: (+1R a +1.5R)
     • Trigger: high >= +1R AND close <= +1.5R
     • Vende: 50% de initial_shares
     • Stop: mueve a entry_price
     • Flag: tp1_hit = True
     • Log: "✅ FASE 1: {symbol} - 50% vendido..."

   FASE 2: (+2.5R o ADR)
     • Condición: tp1_hit == True
     • Trigger A: high >= +2.5R
     • Trigger B: |close - open| >= 80% ADR
     • Vende: 30% de initial_shares
     • Flag: tp2_hit = True
     • Log: "✅ FASE 2: {symbol} - 30% vendido..."

   FASE 3: (Trailing Stop)
     • Condición: tp1_hit == True AND shares > 0
     • Exit: ema_8 < ema_21
     • Fallback: close < sma_20
     • Cierra: 100% de shares restantes
     • Reason: "FASE_3_EMA_CROSS" o "FASE_3_MA20_BREACH"

4. TRACKING EN TRADE RECORD (líneas 381-415)
   ──────────────────────────────────────────
   + initial_shares           # Posición original
   + tp1_executed: bool       # Si ejecutó Fase 1
   + tp2_executed: bool       # Si ejecutó Fase 2
   + final_shares_pct         # % que cerró (20/50/100%)
