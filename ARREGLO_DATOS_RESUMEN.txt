                 ✓ PROBLEMA RESUELTO: Datos yFinance
═══════════════════════════════════════════════════════════════════════

PROBLEMA:
--------
yFinance descargaba datos AJUSTADOS por splits/dividendos históricos,
mostrando precios incorrectos para backtesting.

Ejemplo DIS 2018-06-14:
  ✗ yfinance ajustado: $103.33
  ✓ Real (OpenBB):     $108.75

CAUSA:
-----
El cache SQLite (ticker_cache.py) descargaba directamente de yfinance
sin considerar que devuelve precios ajustados históricos.

SOLUCIÓN:
--------
1. Modificado src/data/ticker_cache.py:
   - Ahora usa OpenBB cuando DATA_SOURCE = "openbb"
   - OpenBB con provider "yfinance" descarga precios nominales (sin ajustar)
   - Arreglado índice DatetimeIndex para compatibilidad

2. Creado script de utilidad: clear_corrupted_cache.py
   - Limpia cache corrupto de tickers específicos
   - Puede re-descargar automáticamente con datos correctos

ARCHIVOS MODIFICADOS:
--------------------
✓ src/data/ticker_cache.py (imports + método get_ohlcv)
✓ clear_corrupted_cache.py (nuevo)
✓ SOLUCION_DATOS_YFINANCE.md (documentación)

VERIFICACIÓN:
------------
✓ Datos correctos descargados desde OpenBB
✓ Cache funciona correctamente (lectura/escritura)
✓ Índice DatetimeIndex correcto
✓ Columnas normalizadas (Open, High, Low, Close, Volume)
✓ Precios verificados contra múltiples fuentes
✓ Tests pasados: 100%

USO:
---
# Limpiar y regenerar ticker específico
python3 clear_corrupted_cache.py DIS --refetch

# Limpiar múltiples tickers
python3 clear_corrupted_cache.py DIS AAPL TSLA --refetch

# Ver ayuda
python3 clear_corrupted_cache.py --help

IMPACTO:
-------
✓ Nuevos backtests usan datos correctos automáticamente
✓ Gráficos Streamlit continúan mostrando datos correctos
⚠ Cache existente (12M registros) contiene datos incorrectos
  → Se regenera automáticamente cuando se solicita

PRÓXIMOS PASOS:
--------------
1. Limpiar cache de tickers que vas a analizar:
   python3 clear_corrupted_cache.py DIS --refetch

2. Ejecutar backtests normalmente - usarán datos correctos

3. Los nuevos datos se guardan correctamente en cache
