📁 1. src/backtest/daily_engine.py (líneas 433-445)
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   
   ANTES:
   ------
   # Calculate RVOL: Current volume vs 20-day average
   avg_volume_20 = df['volume'].rolling(window=20).mean().iloc[-1] if len(df) >= 20 else current_bar['volume']
   rvol = current_bar['volume'] / avg_volume_20 if avg_volume_20 > 0 else 0
   
   PROBLEMA: .rolling() incluye la barra actual → Look-ahead bias
   
   DESPUÉS:
   --------
   # Calculate RVOL: Current volume vs 20-day average (EXCLUDING current bar to avoid look-ahead)
   # Get historical data strictly before today
   prior_bars = df[df.index < today]
   if len(prior_bars) >= 20:
       avg_volume_20 = prior_bars['volume'].tail(20).mean()
       rvol = current_bar['volume'] / avg_volume_20 if avg_volume_20 > 0 else 0
   else:
       avg_volume_20 = current_bar['volume']
       rvol = 0
   
   SOLUCIÓN: Solo usa datos ANTES del día de entrada → Sin look-ahead
