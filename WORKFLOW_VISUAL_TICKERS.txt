  🛡️  VALIDACIONES AUTOMÁTICAS EN CADA FASE
═══════════════════════════════════════════════════════════════════════════════

FASE 1 - Validación:
  ✓ Normaliza a uppercase
  ✓ Elimina duplicados en JSON
  ✓ Filtra tickers ya en DB (query SQL)
  ✓ Genera lista limpia

FASE 2 - Descarga:
  ✓ Retry con backoff exponencial (429, 503, etc.)
  ✓ Thread-safe (cada worker su propia conexión)
  ✓ Valida mínimo 50 días de data
  ✓ Detecta tickers delisted
  ✓ Maneja MultiIndex de yfinance

FASE 3 - Indicadores:
  ✓ Valida mínimo 20 días para SMAs
  ✓ Skips tickers sin datos suficientes
  ✓ Crea backups antes de modificar

FASE 4 - Patrones:
  ✓ Checkpoint cada 10 tickers (auto-save)
  ✓ Merge mode preserva cache existente
  ✓ Valida mínimo 150 días de historia
  ✓ Error handling por ticker (no falla todo)
  ✓ Confidence scores normalizados [0-1]

FASE 5 - Auditoría:
  ✓ Detecta gaps mayores a 5 días
  ✓ Valida rangos de precios (outliers)
  ✓ Reporta tickers con <100 días
