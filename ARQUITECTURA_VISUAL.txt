╔════════════════════════════════════════════════════════════════════╗
║                  SYSTEM DE VALIDACIÓN                              ║
╚════════════════════════════════════════════════════════════════════╝

  Cada feature pasa por 4 fases automáticas:

  Phase 1: CONVERGENCE TEST
  ─────────────────────────────────────────────────────────────────
    ✅ THOR vs Advanced < 20% diff en Sharpe
    ✅ Trades similares (±30%)
    
    $ python3 validation_baseline.py --phase 1


  Phase 2: FEATURE IMPACT
  ─────────────────────────────────────────────────────────────────
    📊 Sharpe Delta calculado
    ✅ ENABLE si delta > +0.1
    ⚪ NEUTRAL si delta ≈ 0.0
    ❌ DISABLE si delta < -0.1
    
    $ python3 validation_baseline.py --phase 2


  Phase 3: PRODUCTION CONFIG
  ─────────────────────────────────────────────────────────────────
    🔧 Auto-genera config con features habilitadas
    
    Automatic - no command needed


  Phase 4: RE-OPTIMIZATION
  ─────────────────────────────────────────────────────────────────
    🔍 Re-optimiza parámetros CON la nueva feature
    📊 Nuevos parámetros óptimos guardados
    
    $ python3 validation_baseline.py --phase 4


  Phase 5: WALK FORWARD (opcional)
  ─────────────────────────────────────────────────────────────────
    🚀 Valida robustez en múltiples ventanas
    
    $ bash run_walk_forward.sh
